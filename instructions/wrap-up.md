## Where to Take This Next

A few things worth exploring on your own:

**Cursor Rules** — add a `.cursorrules` file to your project to give the Agent standing context about your codebase, coding standards, and patterns. It makes every prompt sharper.

**Multi-file edits** — ask Agent to refactor across multiple files at once. For example: *"Rename the `canonicalOrder` variable to `normalizedOrder` everywhere it appears."*

**Test generation** — ask Agent to write MUnit tests for the `normalize-order.dwl` transforms. It can generate realistic test payloads for all three input formats.

**Cursor Tab** — beyond Agent, Cursor's Tab completion predicts multi-line edits based on what you're doing. Try it while making changes to `order-api.xml`.
